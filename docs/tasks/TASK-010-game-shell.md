# TASK-010：游戏主界面完善

## 状态

已完成。该任务只整理现有游戏页面，不改变领域规则、API契约或存档格式。

## 实现摘要

- 在现有 Vanilla TypeScript 页面外增加统一游戏壳层。
- 顶部状态栏显示角色、游戏天数、revision和修炼状态。
- 统一总览、修炼、物品导航，并保留各页面既有操作。
- 增加人物信息侧栏，集中展示姓名、先天禀赋和已选词条。
- 增加笔记本常见宽度下的响应式布局和移动端堆叠规则。
- 保持原有后端权威状态、忙碌态、错误反馈和revision冲突刷新语义。
